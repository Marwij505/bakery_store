# Bakery Store Management System

Bakery Store Management System is a web-based store management application designed to help business owners, managers, and administrators manage daily store operations through a centralized system.

The application was developed using Python Flask and MySQL, with a focus on authentication, role-based access, product management, and administrative functionality.

This project was created as an academic project to practice backend web development, database integration, authentication, session management, and user access control.

---

## Features

### User Authentication

- User login and registration
- Session-based authentication
- Secure password handling
- User access management

### Role-Based Access Control

The application supports different management roles, including:

- **Owner**
- **Manager**
- **Administrator**

Each role can access management functionality according to the structure of the application.

### Dashboard

The system provides a centralized dashboard where authorized users can access important store management information and application features.

### Product Management

Authorized users can manage product-related information through the system, including store products and other related data.

### Store Management

The application is designed to support internal store operations and provide business owners and management staff with a structured interface for managing store-related activities.

## User Roles

### Owner

The Owner represents the highest-level business user in the system and is intended to oversee overall store management and administrative activities.

### Manager

The Manager role is designed to assist with operational management and store-related activities.

### Administrator

The Administrator role supports system administration and management functionality within the application.

## Project Purpose

The main purpose of this project was to develop a database-driven web application that simulates an internal store management system.

Through this project, I practiced several web development concepts, including:

- Flask application development
- MySQL database integration
- User authentication
- Session management
- Role-based access control
- CRUD operations
- Backend and frontend integration
- Database-driven application development

---

## Project Structure

The application follows a Flask-based web application structure that connects the frontend interface with backend application logic and a MySQL database.

The system is designed primarily for internal management users rather than customers, allowing store owners and authorized staff to manage business operations through a centralized web interface.
